# 模板代码系统 · 设计定稿（实施前评审版）

> 本文档是实施的唯一依据。所有决策已经逐分支确认（见 docs/adr/0001-template-code-system.md）。实施时任何偏离本文档的行为都应先回到本文档修订。

## 1. 目标

- 代码块通过 YAML 头声明元数据；可被自动收集、搜索、自定义
- 公共代码收敛为 utils 模板，挑战中引用并传参
- 读者（前端/复制/下载/kb.json）看到的永远是替换后的最终内容，与现状排版一致

## 2. 文件格式

### 2.1 挑战文件（lua/challenges/）固定骨架

```
<文件头：连续普通注释，自由行数，原样直通>     ← 多数 1 行，少数多行
<前置代码块（必需，编号 0 起）>
--===--                                       ← 分隔线：固定字面量，全文件恰好一次
<代码块 1..N>
<后置代码块（必需，继前续编号）>
```

### 2.2 工具文件（lua/utils/）

自由格式，无骨架约束、无前后置要求。模板代码的唯一宿主目录。

### 2.3 代码块

- **自定义代码块** = 一个 YAML 头 + 一条代码行
- **模板引用块** = 仅一个 YAML 头（代码由构建期从模板展开）
- 代码块之间空行非必要
- 输出时每个代码块 = 自动编号的说明注释块 + 一条替换后的代码行

## 3. YAML 头与 schema

YAML 头 = `--[[` 与 `]]` 包裹的 YAML 文档。键名用中文。

```yaml
# ── 通用 ──
模板: soul-spawn          # 省略 = 自定义代码；填了 = 使用模板（值为模板id, string）
说明: ...                 # 使用模板时可省略（复用模板说明插值结果）；自定义代码必填；
                          # 若填写则整段覆盖模板说明（不做部分替换）
参数: {P1: [3, 34]}       # 使用模板时可省略（全用默认值）；值为标量或列表

# ── 自定义代码专用 ──
作为模板: true            # 省略 = false；仅在 lua/utils/ 内有效，challenges 中出现则构建警告
名称: 灵魂队列             # 被同文件其他块依赖时必填；文件内作用域；模板引用块也可声明
依赖: 增益管理             # 可省略；值为同文件某块的名称（string）

# ── 模板专用（作为模板: true 时必填）──
模板id: soul-spawn        # 全局唯一字符串，构建期查重，重复即报错
参数定义:
  P1: {类型: 道具id, 默认: 653, 性质: 局部}
```

### 3.1 模板id

显式字段，不用文件名。全局唯一，构建期查重。

### 3.2 参数占位符

- 模板代码体内以全局名形式出现 `P1`、`P2`…`Pn`
- 替换按 token 边界匹配（不允许是字符串、注释或其他标识符的子串）
- 参数值允许列表：进代码用 `,` 连接，进文本用 `、` 连接
- 模板说明中用 `{P1}` 插值槽引用同一套参数
- 未指定的参数取模板默认值；引用了模板未定义的参数 → 构建报错

### 3.3 性质

仅文档标注：`全局` = 该参数对应代码中的全局变量，玩家可在控制台手改；`局部` = 内联值。构建期不做任何处理。

### 3.4 依赖

值为同文件某块的 `名称`。构建期校验：① 该名称存在；② 对应块在当前块之前。违反即构建报错。不做代码内联。

## 4. 替换与校验（构建期，GenerateHtml.py）

1. 解析所有文件，收集 utils 中的模板注册表（模板id → 定义）
2. 展开模板引用块：取模板代码 → 参数占位符替换（token 边界）→ LuaMin 语法校验（fengari/luaparse）→ 生成块代码
3. 依赖校验、模板id 查重、骨架校验（分隔线恰好一次、前后置存在）
4. 编号：所有代码块按文件顺序从 0 连续编号，后置拿最后一个号
5. 输出：说明注释块（编号 + 插值后的说明）+ 替换后代码行；YAML 头不出现在任何输出中

## 5. 输出契约

- 前端详情页、复制代码、下载模组 zip、kb.json：内容 = 替换后的最终代码与说明，排版与现状一致
- kb.json 结构化输出：文件级信息 + blocks（每块 num/comment/code 及可选 region/deps/name/tpl/tplDef/params/values/body/commentTpl）；可自定义块自包含 body/commentTpl/params，下游可复现“注释 + 代码双自定义”；`text`（剥 `l ` 前缀整文件）/`code`（组装格式整文件）仍保留
- 前端与构建器新增多行注释支持：`--[[ ]]` 块、以及 `--[[ 注释 ]]代码` 同行内联形式

## 11. 前端自定义参数面板（2026-09-17 追加）

详情页展开"使用模板"的条目时，代码框上方显示参数面板：3 列 N 行——左列（不可修改）= 参数名（含全局/局部性质标注）；中列 = 参数说明；右列 = 输入框，默认显示当前值。输入即时生效：说明文本（{P1} 插值）与代码（token 边界替换）同步重渲染，即浏览器内完成 DIY。

数据契约（构建器与前端的对齐点）：

- 构建器在 page.js 的 `__ALL_TEMPLATES__` 占位符注入模板注册表：`{模板id: {body: "含P1..Pn的代码", params: {P1: {说明, 性质, 默认}}}}`
- 使用模板的代码块数据：`{comment: 插值后说明, code: 替换后代码, tpl: "模板id", values: {P1: 当前值}}`；自定义代码块：`{comment, code}`（无 tpl/values）
- 前端替换与构建期同一算法（token 边界；列表进代码 `,`、进文本 `、`）；复制/下载使用面板当前值生成的内容，未改动时与构建产物一致
- 语法校验只在构建期做；前端编辑不做运行时校验（参数面板按类型提示约束输入）
